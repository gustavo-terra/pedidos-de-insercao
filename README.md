# pedidos-de-insercao
Aplicação desenvolvida em Python para automatizar o preenchimento de Pedidos de Inserção (PIs) utilizados por agências de publicidade

A proposta é utilizar planilhas como modelos configuráveis, permitindo o preenchimento dinâmico de informações,
a distribuição de inserções por período e a geração automatizada de documentos em PDF.
